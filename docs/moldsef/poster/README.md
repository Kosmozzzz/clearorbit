# A0 poster

- **`ClearOrbit_poster_A0.pdf`**: the file to print. It is one vertical A0 page (841 × 1189 mm). Print it at 100 %, with no "fit to page".
- **`preview.png`**: a small preview of the poster for screens.
- **`poster.html`**: the poster as a web page. It is generated by `build.mjs`, so don't edit it by hand.
- **`img/`**: screenshots of the live app and the two QR codes. The QR codes point to the live app and to the GitHub repository.

Every number and chart is read from `research/results/benchmark.json`. If you re-run the benchmark, rebuild the poster with these commands (Windows, Git Bash):

```bash
node docs/moldsef/poster/build.mjs
"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --no-pdf-header-footer --virtual-time-budget=8000 --print-to-pdf="$(cygpath -w "$PWD/docs/moldsef/poster/ClearOrbit_poster_A0.pdf")" "file:///$(cygpath -w "$PWD/docs/moldsef/poster/poster.html")"
```

Poster rules (MoldSEF / Infomatrix): one vertical A0 poster, no external company logos and no old medals. Every visual on the poster is drawn in code or is a screenshot of the project itself.
